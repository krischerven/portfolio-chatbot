# README

## About
This is the server for the chatbot on https://krischerven.info/. You can find the client code at [https://github.com/krischerven/portfolio-webpage](https://github.com/krischerven/portfolio-webpage/blob/d7acb315cb51bad4b639d85b2cc8d8c70d4171a8/main.py).

## Running locally
While this chatbot is meant to be accessed from a frontend, you can also run it locally. You will need to have a recent version of Go installed on your computer.

```bash
./run
```
